# Verse — Caption & Lyric Studio

A canvas and timeline editor for video captions and song lyrics. Built with React, Vinext and Mediabunny.

## Run locally

Use Node.js 22.13 or newer. Install dependencies with `npm ci`, then run `npm run dev`. The local preview opens at http://localhost:5173.

`npm run build` produces a Cloudflare-compatible Worker in `dist/server` and browser assets in `dist/client`. `.openai/hosting.json` identifies the existing private Site; reuse it when publishing.

## Editing

- Import a video or audio clip, up to twelve minutes and 1 GB.
- Generate captions through the AI workflow, import SRT/VTT subtitles, or add captions manually.
- Double-click text on the canvas to edit. Highlight words to change only their size, color, bold or italic formatting.
- Drag captions and their scale handles. Shift/Ctrl/Cmd-click clips to select multiple captions.
- Move and trim timeline clips, split at the playhead, duplicate, merge, delete, copy formatting, or undo/redo.
- Save a `.verse.json` project from the project menu. Media is not embedded: relink the original file when reopening. Download SRT captions from the same menu.

## On-device AI

Open **Generate captions** or **On-device AI** from the project menu. Choose separation, transcription, or both, then **Process on this device**. No Python installation, API keys, processing account, or paid inference API is used. The previous provider routes and key fields have been removed.

The browser downloads open model weights from Hugging Face and runtime files from jsDelivr. Audio never leaves the device. Models are cached when browser storage allows; browser eviction or private browsing can require another download. First use needs an internet connection and roughly 350 MB for both models and runtimes. Full offline app installation is not provided.

- **Separation:** HTDemucs ONNX, 44.1 kHz stereo, with overlapping segments. The instrumental track is the sum of drums, bass, and other instruments. WebGPU is preferred, with a CPU fallback when session initialization fails.
- **Transcription:** quantized multilingual Whisper Base with word timestamps, running through Transformers.js on the CPU. It prefers isolated vocals when available. Every generated caption is flagged for review; this model does not provide calibrated word confidence scores.
- Processing runs in a separate browser worker. Cancel terminates the worker immediately and releases model memory. Existing captions remain until transcription completes.

Use current desktop Chrome or Edge and keep the tab open. Separation can take several minutes and needs substantial memory. Speech recognition, especially sung lyrics, can contain errors; this smaller browser model is not identical to the Python example's Whisper Small. Review wording and timing before export.

Browser worker bundles are generated by `scripts/build-local-ai.mjs` during dev/build, separately from Vinext's page bundle. Weights are pinned by repository revision. Model sources: [Demucs Web](https://github.com/timcsy/demucs-web), [HTDemucs ONNX](https://huggingface.co/timcsy/demucs-web-onnx), and [Whisper Base timestamped](https://huggingface.co/onnx-community/whisper-base_timestamped).

## Typography and export

Inter is the default family. Inter, Lora, and Montserrat include regular, bold, and italic styles. Gill Sans MT and other system fonts are available when installed. Upload TTF, OTF, WOFF, or WOFF2 files under a family name, adding available variants separately. Custom fonts work in preview and export for the current session; reload their files when reopening the app. Missing fonts use stable Arial metrics. Font measurements update after the family resolves, without resizing the canvas.

Caption bounds hug the visible text. Drag a corner to proportionally resize editable mixed typography. Center anchors preserve the center as wording, font, and size change. Single-line or multi-line layout, maximum words/characters/lines, and punctuation/pause-aware reflow are available. Unbroken words are never cut to meet a character limit.

Select words directly on the canvas, or Shift/Ctrl-click caption blocks for bulk editing. Bold, Italic, and Bold Italic toggle on and off. “Preserve word styling” keeps intentional size ratios and custom colors during bulk changes. Apply typography or position to all captions, or change the edit scope to all.

Timeline clips support group movement and group edge trimming. Clips snap to other caption edges, word boundaries, and the playhead. The playhead snaps to caption edges; canvas guides snap text to the horizontal, vertical, or exact center. Clicking a caption seeks to its start. Playback follows the active caption and scrolls the transcript.

Each caption has separate In and Out animations: None, Fade, Slide, Scale, Blur/focus, Pop, or Type/reveal, with duration and easing controls. Short captions proportionally fit both animations into the available time. The editable text remains available while paused.

The audio mixer independently controls original audio, vocals, and instrumental tracks with mute, solo, and volume. Multiple solos can play together. The default export uses the current mixer, including a fully silent mix.

Optional Auto Emphasis runs a quantized MiniLM meaning model locally (about 25 MB on first use), then combines semantic relevance with emotion/action words, word timing, pauses, and isolated vocal energy when available. Choose intensity and permitted styles, target selected captions, regenerate, or remove only automatic emphasis. Manual overrides remain editable and survive automatic-emphasis removal. Meaning analysis works best in English and is an editorial suggestion, not a reliable measure of emotion or intent.

Preview and MP4 export share the same caption renderer. Exports support 1080p/4K and 30/60 FPS, H.264 video, and 256 kbps AAC audio. A bundled portable AAC encoder supports browsers without native encoding. Device video-codec support and available memory can limit large exports. Exported files remain local.
